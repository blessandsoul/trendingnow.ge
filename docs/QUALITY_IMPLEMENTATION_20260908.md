# TrendingNow — реализованная волна качества

8 сентября 2026. Локальная реализация, не production-релиз. Запрос владельца: внедрять только то, что действительно повышает качество. Исходные 100 предложений сохранены в `RETENTION_SEO_100_IMPROVEMENTS_20260908.md`; этот документ не объявляет все 100 выполненными.

## Что изменилось для покупателя

- Главная, каталог и точные предложения соединены: 18 записей PCShop/Elite доступны из основного `/products`, а не только из отдельного preview. Старые 18 карточек и история прежней модели сохранены.
- Поиск принимает грузинские названия, основные синонимы и латинское `mausi`. Ввод не теряет фокус; одна отправка создаёт один URL. Работают бюджеты, сброс, возврат из карточки и восстановление запроса.
- На карточке видны точная модель, SKU, продавец, цена с датой проверки и место покупки. Неизвестное наличие не становится «в наличии». Покупатель переходит в конкретный магазин; контрольный редирект не принимает произвольный URL.
- Сохранение работает без регистрации на этом устройстве, с отменой удаления, восстановлением после перезагрузки и обновлением второй вкладки. При запрете хранения явно предупреждаем о временном режиме. Синхронизацию с аккаунтом не обещаем.
- Сравнение сохраняет до трёх товаров одного подтверждённого типа. В текущих данных это мыши и ноутбуки; несовместимые типы и неизвестные параметры не получают выдуманных характеристик.
- Общие Noto Sans Georgian/Anton, текстовый wordmark, кобальтовые/жёлтые акценты, шапка и footer используются публичными шаблонами. Первый отдельный жест вверх показывает содержащийся внутри шапки поиск, следующий — полную шапку.
- «О нас», FAQ, доставка, оплата, гарантия, контакт и страница для магазинов переписаны на KA/EN/RU под внешнюю покупку. Вход описывает прежний аккаунт, не новый собственный checkout.
- Архивная корзина не обещает наши тарифы/наличие и не оформляет новый заказ. В старых товарных блоках убраны новые cart CTA и неподтверждённые промо-значки. Произвольный номер не показывает успешный заказ: требуется локальная квитанция фактического ответа API. Это не подтверждение оплаты и не повторная серверная проверка статуса.
- У контактов рабочие mailto/tel; сообщение об ошибке содержит точный SKU/ссылки. Инертная подписка заменена честным обращением по email. Авторассылка не заявляется.
- Убраны выдуманные `InStock/Offer` из старой товарной разметки, тип собственного магазина заменён организацией. Sitemap больше не меняет дату блога при каждой сборке. Незавершённые preview и новые карточки не получили массовый SEO-допуск.

Skill-контекст: `trendingnow-site` удержал внешнюю потребительскую модель и общий Bold Discovery; правила Georgian typography и frontend-design применены к общей системе. `seo-autocontent` admission не позволяет объявить все50 подготовленных файлов принятыми по механическому lint: источник, самостоятельная польза, грузинская редактура и основания изображений ещё открыты. Это ограничение публикации контента не остановило локальные исправления UI.

## SEO-основание точечных изменений

Правдивый `lastmod` отражает существенное изменение страницы, не время сборки: [Google Search Central](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap). Редакционная модель допускает Product snippets при выполнении требований; снятие ложных Offers не делает карточку автоматически eligible: [Product snippets](https://developers.google.com/search/docs/appearance/structured-data/product-snippet). Индексация, позиции, Discover и рост возвратов не подтверждены этим локальным QA.
